# Changelog

One section per release, newest first. A release is one distro, tag
`<distro>-YYYYMMDD[.N]`, which publishes `husarion/ros:<distro>-ros-core-YYYYMMDD[.N]`
and `husarion/ros:<distro>-ros-base-YYYYMMDD[.N]` and moves `<distro>-ros-core`
and `<distro>-ros-base`. The GitHub release of the tag carries the index
digests. `just release <distro>` writes the sections.
